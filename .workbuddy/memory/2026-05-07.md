## 部署相关（20:03 补充）

### 创建的文件
- `deploy-github-pages.js` - Node.js GitHub Pages 推送脚本（将 website/ 复制到临时目录后推送）
- `deploy-gh-pages.bat` - Windows 批处理版 GitHub Pages 推送脚本
- `push-to-github.js` - 原项目推送脚本（推送整个项目）
- `git-push-v2.sh` / `git-push.sh` / `push-ssh-v2.bat` - 其他推送脚本

### 部署流程
1. **前端 (GitHub Pages)**: 运行 `deploy-gh-pages.bat` 或 `node deploy-github-pages.js`
2. **后端 (Cloudflare Workers)**: 需要 wrangler 部署 + D1 数据库初始化
3. **API 配置**: 推送后编辑 `website/app.js` 第7行 API_BASE 为 Workers 地址

### 注意事项
- GitHub Pages 需要 website 文件夹内容在仓库根目录
- Cloudflare 需先 `wrangler login` 认证
- 两个部署可并行进行
